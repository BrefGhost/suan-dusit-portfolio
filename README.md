# Suan Dusit University — Special Affairs Internship Portfolio (v2)

เปิด `index.html` ในเบราว์เซอร์ได้เลย (ไม่ต้องติดตั้งอะไร ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์ Kanit/Prompt)

- `index.html` โครงหน้า | `style.css` สไตล์และเอฟเฟกต์ | `script.js` ข้อมูลและการทำงาน
- แก้ข้อมูลนักศึกษา/โปรเจกต์ได้ที่อาร์เรย์ `interns` และ `projects` ต้นไฟล์ `script.js`
- โลโก้ในเฮดเดอร์ (`.logo-placeholder`) และภาพโปรเจกต์ทั้งหมดยังเป็นตัวอย่าง รอเปลี่ยนเป็นไฟล์จริง

## v2.1 เอฟเฟกต์ขยับสมูท
- เลื่อนด้วยลูกกลิ้งเมาส์แบบหน่วงนุ่ม (ทัชแพดและมือถือใช้การเลื่อนปกติ)
- แถบความคืบหน้าการเลื่อนด้านบน, เฮดเดอร์หดตัวเมื่อเลื่อน, แถบเมนูเลื่อนตามส่วนที่กำลังดู
- พาดหัวและภาพในการ์ดเลื่อนต่างระดับ (parallax), แสงสปอตไลต์ตามเมาส์บนการ์ด, ข้อความค่อยๆ ชัดขึ้น, หน้าต่างรายละเอียดเด้งเข้า

## v2.2 สวยๆ เด้งๆ
- ทรงลอย 3 มิติ (วงแหวน/ก้อนมน/ลูกบอล) ในหน้าแรก ลากแล้วดีดกลับได้, พื้นหลังแสงเคลื่อนไหว, ตัวอักษรไล่สีเคลื่อนที่
- ปุ่มมีแสงวาบ, ปุ่มกรองเด้งเมื่อเลือก, การ์ดเด้งเข้าทีละใบ, อวาตาร์ลอยขึ้นลง, ไอคอนสั่นเรียกความสนใจ
- รอยประกายตามเมาส์, ปุ่มเด้งกลับขึ้นด้านบน, คอนเฟตติเมื่อเลื่อนถึงท้ายหน้า

## v3 สุดความสามารถ
- พรีโหลดเดอร์ตัวเลขนับ 0-100 แล้วม่านปัดขึ้นด้วยขอบโค้ง ก่อนพาดหัวร่วงลงมา
- ส่วน 'จับ ลาก โยน': ลูกบอลฟิสิกส์ 4 ฝ่าย (แรงโน้มถ่วง ชน เด้ง ยืดหดตามความเร็ว ลากแล้วโยนได้) แตะลูกบอลฝ่ายเพื่อกรองผลงานและเลื่อนไปที่ผลงานทันที
- กรองผลงานมีแอนิเมชันออกก่อนเข้า และสีออร่าของส่วนผลงานเปลี่ยนตามฝ่ายที่เลือก
