## v2.1 เอฟเฟกต์ขยับสมูท
- เลื่อนด้วยลูกกลิ้งเมาส์แบบหน่วงนุ่ม (ทัชแพดและมือถือใช้การเลื่อนปกติ)
- แถบความคืบหน้าการเลื่อนด้านบน, เฮดเดอร์หดตัวเมื่อเลื่อน, แถบเมนูเลื่อนตามส่วนที่กำลังดู
- พาดหัวและภาพในการ์ดเลื่อนต่างระดับ (parallax), แสงสปอตไลต์ตามเมาส์บนการ์ด, ข้อความค่อยๆ ชัดขึ้น, หน้าต่างรายละเอียดเด้งเข้า

## v2.2 สวยๆ เด้งๆ
- ทรงลอย 3 มิติ (วงแหวน/ก้อนมน/ลูกบอล) ในหน้าแรก ลากแล้วดีดกลับได้, พื้นหลังแสงเคลื่อนไหว, ตัวอักษรไล่สีเคลื่อนที่

- รอยประกายตามเมาส์, ปุ่มเด้งกลับขึ้นด้านบน, คอนเฟตติเมื่อเลื่อนถึงท้ายหน้า

## v4.4 แก้บั๊ก
- ตัวเลขบนการ์ดลอยในหน้าแรกแสดง "7" โปรเจกต์ → แก้เป็น 8 ให้ตรงกับข้อมูลจริง
- กริดผลงาน 8 ใบเหลือช่องว่างในแถวสุดท้าย → เพิ่มเลย์เอาต์สำหรับ 8 ใบ (2 ใบกว้าง + 3 + 3)
- จำนวนการ์ด (`data-n`) ไม่อัปเดตเมื่อเปิดโหมดลดการเคลื่อนไหว → ตั้งค่าใน `renderProjects()` โดยตรง
- แอนิเมชันการ์ดเข้า (`fill-mode: both`) ทับเอฟเฟกต์ยกการ์ด/เอียง 3 มิติตอนเอาเมาส์ชี้ → เปลี่ยนเป็น `backwards`
- เปิดรายละเอียดโปรเจกต์ใหม่แล้วหน้าต่างค้างตำแหน่งเลื่อนของโปรเจกต์ก่อน → รีเซ็ตกลับด้านบนทุกครั้ง
- เลื่อนลูกกลิ้งเมาส์ระหว่างพรีโหลดเดอร์ทำให้หน้าเลื่อนอยู่ด้านหลัง → รอให้โหลดเสร็จก่อน
- `Intl.Segmenter` ไม่รองรับในเบราว์เซอร์เก่า ทำให้สคริปต์ส่วนที่เหลือหยุดทำงาน → ตรวจสอบก่อนใช้
- ลูป requestAnimationFrame เขียน CSS variable ที่ root ทุกเฟรมแม้หยุดเลื่อนแล้ว (เปลือง CPU/แบตเตอรี่) → เขียนเฉพาะเมื่อค่าเปลี่ยน
- ปุ่มเมนูมือถือค้างเป็น ✕ เมื่อปิดเมนูผ่านลิงก์ฝ่าย → รวมเป็นฟังก์ชัน `closeMenu()` และกด Esc ปิดเมนูได้
- เอฟเฟกต์เอียง 3 มิติของหน้าแรกทับ `scale()` บนจอเล็กหลังย่อหน้าต่าง, แถบเมนูไม่ขยับตามเมื่อปรับขนาด → แก้แล้ว
- แสงวาบบนภาพปกการ์ดถูกภาพบัง, ปุ่มกลับด้านบนที่ซ่อนอยู่ยังกด Tab ไปโดนได้, ภาพย่อแรกถูกไฮไลต์ทั้งที่ด้านบนแสดงภาพปก → แก้แล้ว
- เพิ่มโฟลเดอร์ `videos/` พร้อม `README.txt` ที่เอกสารอ้างถึงแต่ยังไม่มี
